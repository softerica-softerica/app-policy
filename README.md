# App Policies

Hosting for privacy policies of multiple apps, served via GitHub Pages from `main` (root).

Structure: one folder per app/store variant, each with its own `index.html`.

- `inslider/` — Inslider, Google Play version
- `inslider-hw/` — Inslider, Huawei AppGallery version (payments wording adjusted)
- `yoni-hw/` — Yoni (menstrual-cycle tracker), Huawei AppGallery version — `index.html` (EN), `ru.html` (RU)

Enable GitHub Pages (Settings → Pages → Deploy from branch: `main` / root) and use
`https://softerica-softerica.github.io/app-policy/<folder>/` as the privacy policy
URL in the corresponding store listing.
